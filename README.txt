カラコン手帳 - GitHubで公開するためのファイル一式(フォルダなし版)
================================================================

■ 中に入っているもの(ぜんぶ同じ場所に置く、フォルダなし)
  index.html              アプリ本体
  manifest.webmanifest    ホーム画面に「アプリ」として追加するための設定
  sw.js                   オフラインでも開けるようにする設定
  icon-192.png            アプリアイコン(Android用)
  icon-512.png            アプリアイコン(大)
  icon-maskable-512.png   アプリアイコン(Androidの丸・角丸にも合う版)
  apple-touch-icon.png    アプリアイコン(iPad用)
  favicon-48.png          小さいアイコン
  check.html              インストールできる状態か調べるチェック用のページ
  .nojekyll               空のファイル(見えなくても、入らなくてもOK)

■ GitHubにアップする手順
  1. このZipを端末で解凍する
  2. GitHubのリポジトリを開く →「Add file」→「Upload files」
  3. 解凍したフォルダの中のファイルを、ぜんぶ選んで1回でアップする
     (icon-〜.png と apple-touch-icon.png と favicon-48.png も、忘れずに!)
  4. 下の「Commit changes」を押す
  ※ すでに前のファイルを置いている場合は、同じ名前で上書きされます。
    前の「icons」フォルダは、あっても邪魔にならないので、そのままで大丈夫です

■ ちゃんと置けたか確認する方法(ブラウザのアドレス欄に入れて開く)
  https://ユーザー名.github.io/リポジトリ名/manifest.webmanifest
  https://ユーザー名.github.io/リポジトリ名/icon-192.png
  https://ユーザー名.github.io/リポジトリ名/sw.js
  → 文字や画像が出ればOK。「404」と出たら、そのファイルが置けていません

■ インストールできないときは、チェックページを開く
  https://ユーザー名.github.io/リポジトリ名/check.html
  → ❌が出たところが原因です。全部✅になると、そのページから「インストール」もできます

■ ホーム画面にアプリを置く
  Android(Chrome) : アプリのURLを開く → 右上の「︙」→「アプリをインストール」
                     「ホーム画面に追加」しか出ないときは、ショートカットとして追加されます
                     (ページを開いて、少し待ったり、開き直したりすると出ることもあります)
  iPad(Safari)    : 「インストール」の案内は出ません。共有ボタン →「ホーム画面に追加」
  ※ LINEやXなどの中のブラウザじゃなくて、ChromeやSafariで開いてね

■ データのこと
  ・登録したカラコンや写真は、GitHubには上がらず、使ってる端末の中だけに保存されます
  ・端末ごと・URLごとに別々に保存されます。Claudeの中のデータは自動では引き継がれません
  ・引き継ぎ: 今までのアプリで💾 →「コピー」→ メモ帳に貼って保存
              新しいURLのアプリで💾 → 貼り付け →「復元」を2回押す
  ・iPadは、Safariで開いたときと、ホーム画面から開いたときで、保存場所が別になることがあります

■ 公開するときの注意
  ・公開リポジトリのファイルは、誰でも見られます(背景画像やアイコンも入っています)
  ・自分の登録データは入りません
  ・背景の壁紙画像は、公開してよい画像か確認してから公開してね
